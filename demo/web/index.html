HOW TO READ THE RESULT

结论要能回到原文。

[R]

简历证据

只用于说明候选人在简历中写了什么。未写出的能力应标为“当前无证据”。

[J]

岗位要求

判断必要条件与加分项时，以选中岗位的 JD 原文为准。

[K]

通用知识

帮助给出准备建议，不能替代简历经历或虚构岗位要求。
